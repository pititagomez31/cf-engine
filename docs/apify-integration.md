# Apify 1688 Scraper Integration

This document outlines the field mapping from the raw dataset output of the Apify Actor `zen-studio~1688-wholesale-scraper` to the normalized JSON structure generated by `cf-engine`.

## Sample Reference Data
- **Raw Actor Output Sample:** `docs/samples/1688-sample-raw.json`
- **Normalized Product Sample:** `docs/samples/1688-sample-normalized.json`

## Raw to Normalized Mapping Table

| Normalized Field | Raw Actor Property / Extraction Strategy | Type |
|---|---|---|
| `id` | `item.offerId \|\| item.id` | `string` |
| `title` | `item.title \|\| item.subject \|\| item.name` | `string` |
| `images` | `extractImages(item)` (prioritizes `mainImages`, `images`, `imageUrls`, string or object URIs) | `string[]` |
| `pricing.min` | `item.price?.min \|\| item.priceMin \|\| min(variants)` | `number` |
| `pricing.max` | `item.price?.max \|\| item.priceMax \|\| max(variants)` | `number` |
| `pricing.currency` | `item.price?.currency \|\| 'CNY'` | `string` |
| `pricing.tiers` | `item.quantityPrices` mapped to `{ minQuantity, price }` or `item.priceTiers` | `object[]` |
| `supplier.id` | `item.supplier?.userId \|\| item.supplier?.memberId \|\| item.sellerUserId` | `string \| null` |
| `supplier.name` | `item.supplier?.companyName \|\| item.supplier?.loginId \|\| item.sellerCompanyName` | `string` |
| `supplier.location` | `item.shipping?.location \|\| item.supplier?.address \|\| item.province + item.city` | `string \| null` |
| `supplier.province` | `item.province \|\| item.sellerProvince` | `string \| null` |
| `inventory.total` | `item.stock \|\| item.inventory?.total \|\| item.totalStock \|\| sum(variants)` | `number` |
| `inventory.available` | `inventory.total > 0 \|\| item.isOutOfStock === false` | `boolean` |
| `logistics.weight_kg` | `item.unitWeight \|\| item.weight` | `number \| null` |
| `logistics.origin` | `'CN'` | `string` |
| `logistics.shipping_location` | `item.shipping?.location` | `string \| null` |
| `logistics.post_fee_cny` | `item.shipping?.postFee` | `number \| null` |
| `logistics.is_free_shipping` | `item.shipping?.isFreeShipping` | `boolean \| null` |
| `variants` | `item.skus` mapped to `{ sku, price, stock }` | `object[]` |
